# Décisions techniques

Une page par choix technique durable (stack, bibliothèque, hébergement, structure de la base…).
Nom du fichier : `<numéro>-<sujet>.md`, par exemple `002-hebergement.md`.

On ne supprime jamais une décision. Si on change d'avis, on écrit une nouvelle décision et on passe l'ancienne au statut « Remplacée par 00X ».
Ces pages servent aussi pour la soutenance : elles permettent de justifier chaque choix.

## Modèle

```markdown
# 00X — <Sujet>

Date :
Décidé par :
Statut : proposée | en vigueur | remplacée par 00Y
Ticket : ELT-

## Contexte
Pourquoi il fallait choisir.

## Options envisagées
- Option A : avantages, inconvénients
- Option B : avantages, inconvénients

## Décision
Ce qu'on a retenu, en une phrase.

## Conséquences
Ce que ça implique pour la suite.
```
